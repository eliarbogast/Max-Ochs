# Max Ochs

Website for folk guitarist, poet and folklorist Max Ochs, live at https://maxochs.com/.

## How the site is served

The live site is the `docs/` folder, published by GitHub Pages (custom domain set in `docs/CNAME`).
Edit `docs/index.html`, `docs/css/style.css` and `docs/js/theme.js` directly; changes go live when pushed to `main`.
There is no build step: the site is plain HTML/CSS/JS, based on the Themefisher Influencer template.
